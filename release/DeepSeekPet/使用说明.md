# DeepSeek 桌宠 —— 使用说明

一个悬浮在桌面上的小桌宠：把鼠标放上去会弹出 DeepSeek 余额面板，
余额低于 1 元会自动换成"顶锅哭哭"的形象，还能一键启动 DeepSeek Harness。

## 一、运行

1. 把整个文件夹解压到任意位置（**不要只复制 exe，assets 文件夹必须一起**）
2. 双击 `DeepSeekPet.exe`
3. 第一次运行会自动弹出设置窗口，把 **API Key** 填进去（在
   <https://platform.deepseek.com/api_keys> 获取），点「确定」
4. 桌宠就出现在屏幕上了，余额会自动刷新

> 没有 API Key 也能用，只是面板显示"未配置 API Key"。
> 以后想改设置：**右键桌宠 → 设置…**

## 二、怎么用

| 操作 | 效果 |
| --- | --- |
| 鼠标移到桌宠身上 | 弹出余额面板 |
| 单击桌宠 | 固定面板；再点一次取消固定 |
| 按住拖动 | 挪动位置（会自动记住） |
| **在桌宠上滚滚轮** | 放大 / 缩小（50%~200%，自动记住） |
| 面板里「更换素材…」 | 换成你自己的图片（png/jpg/gif/webp 都行，动图会动） |
| 面板里「启动 DeepSeek Harness」 | 启动 DSH |
| 右键桌宠 | 快捷菜单（刷新 / 设置 / 退出） |
| 双击托盘图标 | 打开余额面板 |

余额默认每 5 分钟刷新一次，可以在设置里改。

## 三、换形象

面板 →「更换素材…」→「从文件加载素材…」，选一张图片即可：

- 支持 **png / jpg / gif / webp / bmp**；gif、动图 webp 会逐帧播放
- 图片会自动缩放到 320 像素高，多大都行（上限 4096 像素）
- 建议用**透明背景**的图片，效果最好
- 想换回来：「更换素材…」→「使用内置素材」

## 四、设置项

设置窗口（右键桌宠 → 设置…）里可以改：

| 项目 | 说明 |
| --- | --- |
| API Key | 查询余额用，保存在你自己的电脑上 |
| 低余额阈值 | 低于这个金额（默认 1 元）就换成"哭哭"形象 |
| 刷新间隔 | 默认 300 秒，最小 30 秒 |
| Harness 启动命令 | 留空自动探测；也可以填 DeepSeek Harness.exe 的完整路径 |
| 开机自动启动 | 勾上就随 Windows 启动 |

## 五、它把我的东西存在哪？

都在 `%LOCALAPPDATA%\DeepSeekPet\`：

- `config.ini` —— 配置（含 API Key，只在本机）
- `pet.log` —— 运行日志，出问题时看它
- `materials\` —— 你加载过的自定义素材

想彻底清干净：退出桌宠，删掉这个文件夹即可。

## 六、常见问题

**Q：桌宠不见了？**
A：看看托盘区有没有图标（双击打开面板）；也可能被拖到屏幕外了，
删掉 `%LOCALAPPDATA%\DeepSeekPet\config.ini` 里的 `window_x/window_y` 两行再启动。

**Q：余额一直显示"查询中…"或报错？**
A：看 `pet.log`。常见原因：API Key 填错、没联网、公司代理拦截。

**Q：截图工具截不到它？**
A：正常现象。桌宠是逐像素透明的分层窗口，Windows 不让普通截屏抓到它。

**Q：杀毒软件报警？**
A：这是自编译的未签名小程序（0.7 MB），如果介意可以自己看源码编译，或加白名单。

**Q：能在 Win7 上跑吗？**
A：不建议。需要 Windows 10 1809 或更高（依赖系统的 WebP/GIF 解码器）。
